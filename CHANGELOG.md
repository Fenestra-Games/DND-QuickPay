# Changelog

## 1.1.0

- All player-facing text now comes from `lang/en.json`, so the module can be translated. See the wiki page on translating.
- The manifest now declares `type`, `media`, `languages`, `changelog`, and relative `license` and `readme` paths.
- The repository is now `Thriceisalways/DND-QuickPay`. GitHub redirects the old address.
- The "GM denied request" chat line now reads "The GM denied NAME's request" (previously "NAME request").
- Added design notes for maintainers (`docs/DESIGN.md`).
- Added a translation check to the automated tests.
